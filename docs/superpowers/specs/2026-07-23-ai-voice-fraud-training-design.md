# 安信伴老 AI 语音反诈训练系统设计

## 1. 文档状态

- 日期：2026-07-23
- 状态：已完成产品方向讨论，待用户审阅书面规格
- 适用范围：第一版答辩级完整系统

## 2. 产品定位

“安信伴老”是一套面向老年人的安全受控 AI 语音反诈训练系统。系统通过模拟诈骗对话，训练老人的识别、核实、拒绝和求助能力；训练结束后生成可解释的能力复盘，并在老人授权后引导家属参与后续练习。

第一版同时服务两个目标：

1. 竞赛和答辩展示：突出 AI 语音模拟、动态对话、主动打断和可解释评估。
2. 毕业设计和工程验收：形成完整业务闭环、清晰技术架构、可测试规则和可部署系统。

系统不承担真实诈骗自动鉴定、资金拦截、执法取证、自动报警或金融风控职责。

## 3. 第一版范围

### 3.1 核心闭环

```text
老人进入训练
→ 完成基础学习与固定分支练习
→ 接受 AI 模拟来电测评
→ 系统生成五维能力复盘
→ 老人确认可分享内容
→ 家属获得能力摘要和行动卡
→ 家庭完成核实练习或安全约定
→ 系统推荐针对性复训
→ 对比训练前后能力变化
```

### 3.2 第一版包含

- 手机优先的老人端 Web/PWA。
- 家庭端授权、摘要、行动卡和复训建议。
- 轻量内容管理端。
- 固定分支学习和受控 AI 动态测评。
- 自动轮流语音对话。
- “冒充客服退款”旗舰场景的主动打断能力。
- 规则为主、AI 辅助的五维能力评估。
- “冒充客服退款”完整场景。
- “保健品营销”扩展场景。
- 多种合成语音角色，必要时使用经过授权的真人录音。
- 云端 AI 服务适配器和四级降级机制。
- 录音短期保存、自动删除和分级授权。
- 疑似真实受骗时退出角色并提供确认式求助。
- 本机开发、局域网或临时 HTTPS 联调、公网演示和本地降级包。

### 3.3 第一版不包含

- 真实电话外呼。
- 完整全双工语音。
- 家属或其他真实人物的声音克隆。
- 未经预约的突然诈骗测试。
- 自动报警、自动冻结资金或自动联系外部机构。
- 社区工作端和多社区组织管理。
- 拖拽式场景编排器。
- 基于真实敏感信息生成针对性诈骗话术。
- 家属默认查看完整录音或逐字对话。

社区端作为后续能力，第一版只在训练任务来源等数据字段上保留扩展空间，不实现组织、分组、社区权限和群体报表。

## 4. 角色与权限

### 4.1 老人用户

- 自主选择学习、练习或模拟来电测评。
- 查看完整个人复盘和能力变化。
- 管理家庭绑定、授权范围及录音保存。
- 决定每次训练结果是否分享。
- 随时终止训练、撤销授权或删除录音。

### 4.2 家庭成员

- 发起绑定邀请，但必须等待老人确认。
- 在授权范围内推荐场景、制定计划和发送提醒。
- 查看能力摘要、家庭行动卡及复训建议。
- 参与共同核实练习和家庭安全约定。
- 默认不能查看逐字对话、完整录音或敏感回答。

### 4.3 内容管理员

- 管理场景阶段、话术策略、风险点及评分规则。
- 配置合成语音角色和固定分支。
- 测试、审核、发布及下线训练内容。
- 查看脱敏后的异常对话和运行记录。
- 不得随意访问用户家庭关系或完整训练录音。

### 4.4 系统管理员

- 管理账号、角色、系统配置和审计日志。
- 处理数据删除、异常账号及服务配置。
- 对高风险操作重新确认并记录审计。

### 4.5 家庭授权模型

家庭绑定和数据授权分别管理。绑定成功不自动开放所有数据。老人可分别授权：

- 查看能力摘要。
- 推荐训练。
- 发送提醒。
- 参与共同复盘。
- 接收经过当次确认的求助信息。

老人可以通过主动邀请建立家庭关系，也可以确认家属发起的邀请。所有绑定均须老人确认。撤销授权后立即阻止新的访问。演示环境使用预置体验账号，不依赖现场短信注册。

## 5. 用户流程

### 5.1 老人训练

老人可以自主选择训练，也可以接受家属推荐。测评开始前，系统明确说明这是模拟训练，检查麦克风并提示终止方式。训练中老人可以随时说出“结束训练”或点击结束按钮。

训练结束后，老人先查看个人复盘，再选择是否分享以及分享哪些摘要。系统不在老人不知情的情况下把详细表现传递给家属。

### 5.2 家庭陪伴

家庭端接收可执行任务，而不是简单的风险标签。家庭行动可以包括：

- 共同查找平台官方客服电话。
- 约定涉及转账时先挂断并独立核实。
- 演练拒绝提供验证码的表达。
- 检查手机是否安装陌生远程控制软件。
- 在指定日期重新训练。

家属完成行动后可以记录完成情况，但该记录不计入老人的能力得分。

### 5.3 疑似真实受骗

当老人提到已经转账、正在提供验证码或正在与可疑人员通话时，安全模块优先中止角色扮演。系统提示停止转账和信息提供，并提供联系家属、银行、平台官方渠道或警方的引导。

只有在老人事先授权且当次确认后，系统才向指定家属发送求助。第一版不自动报警、不自动冻结账户，也不在未确认时向家属发送风险标签。

## 6. AI 训练引擎

### 6.1 统一场景状态机

固定分支练习和动态 AI 测评共用一个状态机，不建设两套对话系统。每个场景定义：

- 诈骗者身份、目标和背景。
- 对话阶段及转换条件。
- 每阶段允许使用的话术策略。
- 老人应识别的风险点。
- 需要观察的安全行为。
- 情绪施压等级和最大持续时间。
- 禁止生成的内容。
- 正常结束、主动终止和安全中止条件。
- 评分规则、复盘材料和家庭行动建议。

固定模式从审核过的话术中选择回复。动态模式由 AI 在当前阶段和允许策略内生成表达，不能自行改变诈骗目标或突破安全边界。

### 6.2 单轮处理流程

```text
老人语音
→ 语音识别
→ 敏感信息过滤与真实受骗检测
→ 意图和安全行为识别
→ 状态机决定下一阶段
→ AI 在约束内生成回复
→ 输出安全检查
→ 语音合成并播放
→ 写入脱敏行为事件
```

系统长期记录的是“拒绝提供验证码”“提出联系官方客服”等行为事件。完整对话不能成为最终评分的唯一依据。

### 6.3 语音交互

所有场景以自动轮流对话为稳定基线。系统检测老人说完后再生成回复。“冒充客服退款”增加主动打断能力：老人开口时立即停止 AI 音频，转入语音识别。

系统必须处理沉默、重复、答非所问、口音和识别失败。连续识别失败时，依次提供重说、识别文字确认、屏幕按钮或固定分支，不直接判错。

第一版提供多种合成角色，可配置年龄感、性别、语速、情绪和表达风格。必要时，固定开场和关键话术可以使用经过授权的真人录音。系统不提供真实人物声音克隆。

### 6.4 安全约束

- AI 不得索取或复述真实密码、验证码、身份证号、银行卡号和详细住址。
- 检测到敏感数据时立即脱敏。
- 检测到真实转账或正在受骗的表达时终止角色扮演。
- 每次训练设置最大轮数、最大时长和压力等级。
- 终止词由本地确定性规则优先识别，不依赖大模型。
- 不使用老人真实订单、健康档案或家庭隐私生成诈骗话术。
- 训练结束后明确解除诈骗角色并进入安抚式复盘。

### 6.5 四级降级

| 等级 | 对话 | 语音 | 评分 |
| --- | --- | --- | --- |
| L1 正常 | 动态 AI | 实时合成 | 规则 + AI 辅助分析 |
| L2 AI 降级 | 固定分支 | 实时合成 | 规则评分 |
| L3 网络降级 | 固定分支 | 预录语音 | 规则评分 |
| L4 设备降级 | 文字与按钮 | 无语音 | 规则评分 |

降级后仍使用同一状态机和评分模型。答辩前准备锁定场景版本的 L3 本地演示包。

## 7. 能力评估与复盘

### 7.1 五维能力

| 能力维度 | 可观察行为 |
| --- | --- |
| 身份核实 | 是否质疑身份，是否通过独立官方渠道核实 |
| 信息保护 | 是否拒绝提供验证码、证件号和银行卡信息 |
| 支付警觉 | 是否拒绝转账、屏幕共享、远程控制或陌生链接 |
| 压力应对 | 面对催促和恐吓时是否暂停操作并坚持核实 |
| 求助终止 | 是否挂断、终止训练、联系家属或寻求官方帮助 |

AI 将自然语言映射为有置信度和证据的行为事件。确定性规则根据事件、场景和重要程度计算最终得分。低置信度事件不得直接触发严重负面结论，应在复盘中标记为无法确认或由其他确定性证据补充。

### 7.2 个人复盘

老人首先看到：

- 一句鼓励性总结。
- 本次识别出的诈骗信号。
- 做得好的具体行为。
- 未识别或处理不当的风险点。
- 对应的脱敏对话证据。
- 五维能力表现。
- 一条最重要的改进建议。
- 推荐的下一次训练。

系统避免“容易被骗”“高危老人”等标签，统一使用“本次训练表现”和“能力成长”等表述。

### 7.3 家庭分享和行动卡

家庭端默认只接收训练主题、能力维度摘要、一至两个薄弱点、陪伴建议和共同任务。老人先查看报告，再确认可分享内容。涉及疑似真实受骗等敏感结论时必须单次确认。

每张家庭行动卡只包含一个明确任务。系统根据行动完成情况安排复训，但不把家属表现计入老人得分。

### 7.4 成长判断

系统对比同类场景中的具体行为变化，而不只比较总分。重复测评时应更换表达、商品背景和话术策略，减少记忆答案带来的虚假提升。

## 8. 双场景设计

### 8.1 冒充客服退款

该场景是第一版完整样板，单次测评目标时长为 3 至 5 分钟。

```text
建立客服身份
→ 声称商品或订单异常
→ 提出退款或赔付方案
→ 索取验证码、要求点击链接或共享屏幕
→ 以退款失效等理由施压
→ 老人核实、拒绝、求助或触发风险操作
```

系统使用虚构商品和平台背景，不读取真实订单。该场景同时支持固定分支、动态 AI、五维评分、家庭行动卡和主动打断。

### 8.2 保健品营销

该场景验证训练引擎能否处理慢节奏、信任积累和持续诱导：

```text
建立健康顾问身份
→ 询问模糊健康状况
→ 包装专家或成功案例
→ 放大健康焦虑
→ 推荐高价产品或限时名额
→ 引导付款、持续购买或隐瞒家属
```

评分重点包括权威核实、医疗边界、夸大承诺、持续诱导和理性决策。该场景允许比客服退款更长的阶段和更缓慢的压力曲线，不能只替换客服场景话术。

## 9. 内容管理

### 9.1 结构化配置

场景配置包含：

- 基本信息和适用难度。
- 阶段、转换条件和可用策略。
- 固定话术与 AI 生成约束。
- 语音角色和情绪强度。
- 风险点与安全行为。
- 禁止内容和敏感信息规则。
- 结束条件和降级内容。
- 评分映射。
- 个人复盘知识。
- 家庭行动卡模板。

第一版使用经过校验的后台表单和结构化配置，不做拖拽式编排。第二个场景接入后，再依据真实共性判断后续抽象方向。

### 9.2 生命周期

```text
草稿 → 测试 → 待审核 → 已发布 → 已下线
```

内容管理员可以在沙盒中试听并模拟不同回答路径。发布前检查缺失阶段、不可达分支、无结束条件、压力超限和缺少降级话术。

发布后生成不可变版本。进行中的训练继续使用启动时的版本，新训练使用最新版本。

### 9.3 异常治理

管理员可以查看脱敏后的越界话术、无法结束、重复回复和评分映射失败等事件。异常内容不自动用于模型训练，也不默认展示完整用户对话。

## 10. 系统架构

### 10.1 总体架构

```text
老人端 / 家庭端 / 管理端（Vue 3 PWA）
                │
         HTTPS / WebSocket
                │
       FastAPI 模块化单体
                │
 ┌──────────────┼──────────────┐
身份授权     训练引擎       评估复盘
场景内容     家庭协同       安全审计
                │
 MySQL / Redis / MinIO
                │
       AI 服务适配器
 ASR / LLM / TTS / 降级实现
```

普通业务使用 HTTPS API。实时音频、轮次状态和主动打断使用 WebSocket。前端不直接调用 AI 服务。

### 10.2 技术栈

- 前端：Vue 3、TypeScript、Vite、Pinia、Vue Router。
- 后端：Python 3.12、FastAPI、Pydantic。
- 数据访问：SQLAlchemy 2、Alembic。
- 数据库：MySQL 8。
- 缓存和短期状态：Redis。
- 音频和素材：MinIO 或兼容 S3 的对象存储。
- 通信：HTTPS API 和 WebSocket。
- 测试：pytest、FastAPI TestClient、前端单元测试和 Playwright。
- 部署：Nginx、Docker Compose、HTTPS。

### 10.3 后端模块

```text
backend/app/
├── api/              # HTTP 与 WebSocket 接口
├── auth/             # 登录、角色和权限
├── users/            # 用户资料
├── family/           # 绑定、授权和家庭行动卡
├── scenarios/        # 场景配置与版本
├── training/         # 状态机和训练会话
├── assessment/       # 行为事件、评分与复盘
├── ai/               # ASR、LLM、TTS 适配器
├── safety/           # 脱敏、终止词和真实受骗检测
├── audit/            # 审计与异常治理
├── storage/          # 数据库、Redis、对象存储
└── common/           # 配置、错误和共享类型
```

实时云端 AI 编排运行在 FastAPI 异步服务中。未来接入本地 ASR、TTS 或大模型时，使用独立推理进程，不在 Web 进程执行重型推理。录音清理和批量报告等任务在实际需要出现后再引入后台任务队列。

## 11. 鉴权与 WebSocket 安全

JWT 是身份凭证，WebSocket 鉴权是建立长连接时验证身份和资源权限的过程，两者不互相替代。

推荐流程：

```text
用户通过 HTTPS 登录
→ 后端签发短期 JWT
→ JWT 写入 Secure、HttpOnly Cookie
→ 浏览器建立同源 WSS 连接并自动携带 Cookie
→ FastAPI 验证 JWT、Origin 和训练会话所有权
→ 通过后接受 WebSocket
```

不把长期 JWT 放入 WebSocket URL。若未来跨域环境无法使用同源 Cookie，则通过已鉴权 HTTPS 接口签发几十秒有效、仅可使用一次的 WebSocket 票据。

WebSocket 建连时必须同时满足：

- 用户身份有效。
- 训练会话属于当前老人用户。
- 场景版本允许使用。
- 会话未结束。

家属即使持有有效 JWT，也不能连接老人的实时训练会话。断线重连必须重新鉴权。账号禁用、会话结束或权限变化时，服务端主动关闭连接。

## 12. 数据与隐私

MySQL 保存账号、授权关系、场景版本、训练会话、行为事件、评分和行动卡。Redis 只保存短期训练状态、限流及临时会话，不作为最终记录来源。

音频默认短期保存于对象存储并自动过期。老人可以立即删除或单次授权延长保存。长期保留脱敏行为事件和必要证据摘要。家属默认不能收听录音。

所有 AI 服务只接收完成当前处理所需的最少数据。密钥仅通过后端环境变量注入，不进入前端、日志或代码仓库。

## 13. 异常处理

### 13.1 语音识别异常

```text
请求重说
→ 显示识别文字供确认
→ 提供大按钮回答
→ 切换固定分支
```

### 13.2 AI 和连接异常

- AI 超时、越界或输出格式错误时不播放原始结果，改用审核话术并降低运行等级。
- WebSocket 短暂断开时恢复当前会话；无法恢复时保存已完成事件，并允许重新开始或稍后继续。
- 状态机和关键训练事件必须持久化，不能只存在于单个 WebSocket 连接内。
- 终止词、敏感信息、真实受骗和过度紧张规则优先于正常对话流程。

## 14. 测试策略

### 14.1 单元测试

- 状态机阶段转换。
- 评分规则和行为映射。
- 家庭分级授权。
- 敏感信息脱敏。
- 终止词和真实受骗检测。
- 场景配置校验。

### 14.2 集成测试

- ASR、LLM、TTS 适配器。
- HTTP 和 WebSocket 鉴权。
- 训练状态恢复。
- 录音自动过期。
- 场景版本切换。
- L1 至 L4 自动降级。

### 14.3 端到端测试

- 老人完成客服退款学习和测评。
- 老人主动打断诈骗者。
- 老人确认分享后家属收到行动卡。
- 未授权家属无法访问摘要。
- AI 服务中断后仍能完成固定训练。
- 保健品场景通过同一训练引擎运行。

### 14.4 安全与可用性测试

- AI 不输出禁止话术。
- 前端和日志不暴露密钥。
- 录音及敏感信息按策略删除。
- 大字体、对比度、点击区域和错误提示适合老人。
- 连续误识别时仍能完成流程。

## 15. 建设里程碑

1. 文字版客服退款训练、状态机和规则评分。
2. ASR、TTS、自动轮流和固定分支练习。
3. 受控 AI 动态测评和五维复盘。
4. 家庭绑定、分级授权、分享确认和行动卡。
5. 模拟来电、主动打断和多语音角色。
6. 保健品营销场景和轻量内容管理。
7. 公网部署、四级降级、安全测试和答辩演示包。

每个里程碑都必须形成可运行版本，不能同时铺开多个半成品模块。

## 16. 验收标准

第一版完成时必须满足：

- 客服退款场景可稳定完成学习、练习、动态测评、复盘、家庭行动和复训。
- 保健品营销通过同一状态机和配置模型接入。
- 最终得分由确定性规则计算，AI 分析结果具有证据并可追踪。
- 老人可以主动打断、终止训练和撤销家庭授权。
- 家属只能访问明确授权的数据。
- AI 服务异常时自动降级，最低仍可通过文字按钮完成训练。
- 原始录音按策略自动删除。
- 疑似真实受骗时退出角色并进入确认式求助。
- 公网版本可供手机体验，同时具备不依赖公网 AI 的本地演示包。

关键技术和体验指标至少包括：

- 老人说完到 AI 开始回复的延迟。
- 语音无法识别时能否自然重试。
- AI 是否越过场景和安全边界。
- 相同对话重复评分的一致性。
- 终止词和真实受骗求助能否正确触发。
- 云端服务中断后能否自动降级。
- 老人能否在不求助开发人员的情况下完成训练。
- 家属能否理解行动卡并完成下一步。

具体数值阈值在完成第一个语音原型并取得实际测量数据后确定，不在没有基准数据时编造目标。

## 17. 答辩演示

```text
家属推荐客服退款训练
→ 老人接到模拟来电
→ 与 AI 语音对话并主动打断
→ 系统展示五维复盘和证据
→ 老人确认分享
→ 家属收到行动卡
→ 展示保健品场景配置
→ 关闭 AI 服务并演示自动降级
```

答辩级完成标准不是页面数量，而是一次稳定、可解释、可降级的完整演示。

## 18. 后续扩展

第一版稳定后，再评估：

- 社区活动、任务分配和匿名汇总。
- 小程序或原生应用。
- 本地语音和模型推理。
- 更丰富的诈骗场景。
- 可视化场景编排器。
- 在明确合规和责任边界后的外部机构协作。

所有扩展必须继续遵守老人知情授权、最少采集、确定性安全规则和可降级运行原则。
