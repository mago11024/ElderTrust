# 安全与隐私

## 1. 目标

安信伴老处理账号、家庭关系、语音、训练行为和能力复盘。安全目标不仅是保护数据，还要防止训练本身造成恐慌、误导、家庭冲突或诈骗能力滥用。

所有实现遵循：

- 最少采集；
- 明确告知；
- 老人控制；
- 最小权限；
- 确定性安全规则优先；
- 可撤销、可删除、可审计；
- 外部 AI 服务可降级。

## 2. 数据分类

### 公开内容

- 已审核发布的反诈知识；
- 不含个人信息的场景介绍；
- 公开项目说明。

### 内部内容

- 场景草稿和提示约束；
- 评分规则；
- AI 异常记录；
- 系统配置和汇总指标。

### 个人数据

- 账号和联系方式；
- 家庭绑定与授权关系；
- 训练会话和完成情况；
- 行为事件、能力结果和行动卡。

### 敏感数据

- 密码、JWT、API 密钥；
- 原始录音和完整转写；
- 身份证号、银行卡号、验证码和详细住址；
- 疑似真实受骗表达；
- 能够对个人造成负面标签的风险结论。

## 3. 数据最小化

- 不读取真实订单、通讯录、健康档案或银行信息用于生成诈骗话术。
- 语音处理只发送当前轮次所需的最少数据。
- 长期保存行为事件和脱敏证据，不默认保存完整对话。
- 家庭端只接收完成陪伴任务所需的摘要。
- 演示和测试使用虚构数据，不使用真实老人数据。

## 4. 身份与权限

### HTTP

- 登录成功后使用短期 JWT。
- 浏览器优先通过 Secure、HttpOnly Cookie 携带凭证。
- 高风险写操作执行身份、角色、资源归属和当前状态检查。
- 前端隐藏按钮不构成权限控制。

### WebSocket

建立连接前校验：

- JWT 或一次性票据有效；
- `Origin` 在允许列表；
- 训练会话属于当前老人用户；
- 场景和会话仍有效；
- 账号状态正常。

长期 JWT 不放在 URL。断线重连必须重新鉴权。家属不能连接老人的实时训练会话。

### 管理员

内容管理和系统管理权限分开。管理员查询个人训练、延长录音、导出或删除数据时记录审计。

## 5. 家庭授权

家庭关系不自动授予数据权限。老人分别控制：

- 查看能力摘要；
- 推荐训练；
- 发送提醒；
- 参与共同复盘；
- 接收经过当次确认的求助。

老人先查看个人报告，再决定是否分享。默认不分享：

- 原始录音；
- 逐字转写；
- 敏感回答；
- 无法确认的高风险判断。

撤销授权后立即禁止新的访问。授权创建、变更、撤销和访问均可审计。

## 6. 录音与转写

- 原始录音默认短期保存。
- 具体保存期限由部署配置确定，并在训练前和授权页明确展示。
- 对象存储记录创建时间、到期时间、删除状态和访问权限。
- 老人可以立即删除或单次授权延长保存。
- 家属默认无权收听。
- 到期删除失败需要重试和告警，不能只依赖前端隐藏。
- 用于排错的转写必须脱敏，并限制管理员访问。

## 7. AI 对话安全

### 输入保护

- 检测并遮蔽验证码、证件号、银行卡号和详细住址。
- 不把与当前训练无关的个人信息发送给 AI。
- 检测终止词和疑似真实受骗表达。

### 生成约束

- AI 只能使用当前阶段允许的诈骗策略。
- 限制最大轮次、时长和压力强度。
- 禁止索取或复述真实敏感信息。
- 禁止提供可直接复用的完整诈骗教程。
- 禁止以真实公安、家属或其他个人的克隆声音进行训练。

### 输出保护

- AI 输出必须在播放前完成结构、阶段和禁止内容检查。
- 检查失败时使用审核话术并降低运行等级。
- 异常输出不得直接展示，也不得自动加入训练数据。

## 8. 语音角色

第一版使用多种合成角色，可设置年龄感、性别、语速、情绪和表达风格。经过明确授权的真人录音只用于固定开场或固定话术。

系统不提供：

- 用户上传声音克隆；
- 家属声音克隆；
- 公安、银行或其他真实人员的仿冒；
- 可下载的诈骗者独立音色包。

## 9. 疑似真实受骗

检测到“已经转账”“正在给验证码”等表达时：

1. 立即停止诈骗角色和音频播放；
2. 明确说明当前训练已结束；
3. 提醒停止转账、停止信息提供和独立核实；
4. 展示用户可以主动选择的求助入口；
5. 只有事先授权且当次确认后，才通知指定家属。

系统不自动报警、不自动冻结资金，也不在未确认时向家属、社区或其他机构发送风险标签。

## 10. 密钥与供应商

- AI、数据库、JWT 和对象存储密钥通过后端环境变量或密钥服务注入。
- 不同环境使用不同密钥。
- 前端包、URL、日志和错误响应不得包含密钥。
- 供应商接入前记录数据类型、传输目的、保存策略和退出方式。
- 供应商异常或不可用时切换降级，不绕过安全检查。
- 密钥疑似泄露时立即撤销、轮换并审计相关访问。

## 11. 日志与审计

应记录：

- 登录、失败登录和账号状态变化；
- 家庭绑定和授权变更；
- 训练开始、结束、中止和降级；
- 场景审核、发布和下线；
- 数据查看、导出、延长保留和删除；
- 管理权限和系统配置变更；
- AI 越界、超时和安全拦截事件。

不得记录：

- 明文密码、JWT 和 API 密钥；
- 完整验证码、证件号和银行卡号；
- 默认完整请求体、完整转写和原始音频内容；
- 未脱敏的供应商请求或响应。

## 12. 安全测试

第一版至少覆盖：

- 家属越权查看和连接 WebSocket；
- 修改会话 ID 访问他人训练；
- JWT 过期和账号禁用；
- 跨站 WebSocket 来源；
- 终止词优先处理；
- AI 生成禁止内容；
- 敏感信息脱敏；
- 录音到期删除；
- 供应商超时和降级；
- 日志敏感信息扫描。

## 13. 上线检查

- HTTPS 和 WSS 已启用；
- Cookie 安全属性和 Origin 列表正确；
- 默认家庭权限为空或最小；
- 原始录音保留策略已展示并验证；
- AI 提示约束和输出检查已启用；
- L2 至 L4 降级可运行；
- 测试和演示数据均为虚构数据；
- 管理员和供应商权限遵循最小原则；
- 数据删除和密钥轮换流程可执行；
- 隐私告知、用户协议和训练免责声明已准备。

## 14. 后续扩展约束

社区端、真实电话、本地模型和第三方机构联动必须单独进行隐私、安全和责任评审，不能因技术接口已预留而默认获得实施授权。
