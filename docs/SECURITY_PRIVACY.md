# 安全与隐私

## 目标

“安信伴老”面向老年用户、家庭成员和社区工作者，涉及个人身份、家庭关系、训练记录、风险评估和社区活动数据。安全与隐私设计必须作为基础能力，而不是上线前补丁。

本文档定义项目的安全与隐私基线。后续实现必须结合具体技术栈、部署环境和合规要求持续细化。

## 基本原则

- 最少采集：只采集实现训练、协同和管理所必需的数据。
- 明确告知：用户应知道采集什么、用于什么、谁能看到、保存多久。
- 授权访问：家庭成员和社区工作者访问数据必须有合法授权或管理依据。
- 最小权限：账号默认只拥有完成职责所需的最低权限。
- 可审计：关键操作必须有日志，便于追踪和问责。
- 可撤回：用户授权应支持撤销，撤销后停止继续展示相关数据。
- 可删除或匿名化：在业务和合规允许范围内支持用户数据删除或匿名化。

## 数据分类

### 公开数据

示例：

- 已发布的反诈知识。
- 公开课程介绍。
- 不含个人信息的宣传材料。

要求：

- 发布前应经过内容审核。
- 避免夸大、恐吓或误导性表达。

### 内部数据

示例：

- 内容草稿。
- 活动配置。
- 汇总统计。

要求：

- 仅授权工作人员可访问。
- 导出时应检查是否含个人信息。

### 个人数据

示例：

- 用户姓名、手机号、账号信息。
- 家庭绑定关系。
- 社区归属关系。
- 训练记录和学习进度。

要求：

- 必须进行访问控制。
- 展示时遵循最小必要原则。
- 日志中避免记录完整个人信息。

### 敏感数据

示例：

- 密码、令牌、密钥。
- 身份证号等强身份标识。
- 精确住址。
- 高风险评估标签。
- 未公开的求助或异常记录。

要求：

- 密码必须使用安全哈希，不得明文存储。
- 密钥不得提交到 Git 仓库。
- 传输过程应使用 HTTPS。
- 导出、查看和修改应记录审计日志。
- 无明确必要时不采集。

## 权限控制

推荐角色：

- 老年用户：访问自己的训练、反馈和授权设置。
- 家庭成员：访问被授权用户的摘要信息。
- 社区工作者：访问所属社区、活动和汇总数据。
- 内容管理员：维护训练内容。
- 系统管理员：管理系统配置、账号和审计。

权限要求：

- 所有接口必须校验登录态。
- 所有涉及他人数据的接口必须校验授权范围。
- 前端隐藏按钮不等于权限控制，后端必须独立校验。
- 管理员高风险操作应记录操作人、时间、对象和结果。
- 批量导出、删除、授权变更等操作应重点审计。

## 家庭协同隐私边界

家庭协同的目标是陪伴和提醒，不是监控。

默认建议：

- 家庭成员可查看训练完成情况、薄弱主题和陪伴建议。
- 不默认展示每道题的具体选择和详细错误记录。
- 老年用户应能查看已授权对象和授权范围。
- 老年用户应能撤销授权。
- 授权变更应通知相关用户。

高风险提醒应谨慎设计，避免给用户贴标签或造成家庭冲突。

## 社区数据边界

社区共育以组织教育和群体服务为主。

默认建议：

- 社区工作者优先查看汇总数据。
- 个人级数据访问必须基于明确服务关系和授权。
- 导出报表默认脱敏。
- 只展示社区职责范围内的数据。
- 社区工作人员离职、调岗或权限变化时，应及时调整账号权限。

## 内容安全

训练内容直接影响老年用户判断，应建立审核机制。

要求：

- 诈骗场景应基于常见真实类型，但避免包含可被滥用的完整作案教程。
- 复盘解释应清晰、准确、不过度恐吓。
- 涉及报警、银行、医疗、法律等内容时，应提示用户联系官方渠道。
- 发布前至少经过内容审核。
- 内容修改应保留版本记录。

## 日志与审计

应记录：

- 登录、退出、登录失败。
- 家庭授权创建、修改、撤销。
- 社区活动创建、分配、导出。
- 内容创建、审核、发布、下线。
- 用户数据查询、导出、删除或匿名化。
- 管理员权限变更。

不应记录：

- 明文密码。
- 完整令牌。
- 完整身份证号或银行卡号。
- 不必要的完整请求体。
- 第三方服务密钥。

日志保存期限应根据业务和合规要求确定，并在上线前明确。

## 密钥与配置

- 所有密钥通过环境变量或密钥管理系统注入。
- 仓库只提交 `.env.example`，不提交 `.env`。
- 生产密钥应定期轮换。
- 不同环境使用不同密钥。
- 发现密钥泄露时，应立即撤销并更换。

## 数据导出与删除

数据导出要求：

- 校验操作者身份和权限。
- 明确导出范围。
- 默认脱敏。
- 记录审计日志。
- 导出文件设置有效期或访问限制。

数据删除或匿名化要求：

- 明确删除范围和影响。
- 保留必要的合规记录。
- 删除后相关统计应不再反向识别个人。
- 如果因业务或合规要求不能删除，应向用户说明原因和保存期限。

## 常见风险清单

- 家庭成员越权查看老人详细训练记录。
- 社区工作者查看非所属用户数据。
- 日志记录了完整手机号、令牌或身份证号。
- 内容未审核直接发布。
- 导出文件长期公开可访问。
- 测试环境使用生产数据且未脱敏。
- 前端做了权限隐藏，但后端接口未校验。
- AI 或第三方服务接收了不必要的个人信息。

## 上线前安全检查

- 权限矩阵已确认。
- 敏感接口有后端鉴权和授权校验。
- 密码、令牌、密钥安全存储。
- 生产环境使用 HTTPS。
- 日志不包含敏感明文。
- 数据导出有审计。
- 内容发布有审核流程。
- 测试数据不包含未经脱敏的真实个人信息。
- 隐私告知、用户协议或授权说明已准备。
