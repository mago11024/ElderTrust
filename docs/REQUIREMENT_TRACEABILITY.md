# 第一版需求追踪矩阵

## 1. 使用规则

本矩阵覆盖 [`REQUIREMENTS.md`](./REQUIREMENTS.md) 中全部第一版需求：P0、P1 功能需求和全部非功能需求。
P2 需求不进入第一版交付，因此 `FR-CONTENT-008` 不在本矩阵中。

- “主要交付里程碑”表示该需求首次具备完整验收证据的唯一里程碑；
- “支撑里程碑”表示继续集成、加固或回归该需求的里程碑，不形成第二个主要归属；
- M1 分为进程内纵向闭环 `M1.0` 和持久化、登录、授权、审计闭环 `M1.1`；
- 修改需求或 Task 目录时必须同步本矩阵，并运行 `python scripts/check_traceability.py`；
- 需求的实现细节仍以需求、架构、安全文档和对应 Task 为准，本矩阵不改写需求语义。

## 3. 维护与校验

校验器从需求文档提取 P0、P1 和无显式优先级的 NFR，排除 P2；再检查矩阵中的需求 ID、优先级和主要
交付里程碑。允许的主要交付里程碑只有 `M1.0`、`M1.1`、`M2`、`M3`、`M4`、`M5`、`M6` 和 `M7`。

校验失败时不得推进依赖本矩阵的 Gate。支撑里程碑用于说明回归责任，不能替代唯一的主要交付里程碑。
