# 正式开发前检查清单

## 1. 使用方式

本清单用于 M0 文档基线结束到 M1 工程开发开始之间的准备。只有“启动阻塞项”全部关闭后，才进入正式功能开发；原型验证项可以随对应里程碑关闭。

状态约定：

- `[x]`：已有文档或仓库证据；
- `[ ]`：尚未完成；
- “启动阻塞”：不完成会导致工程立即返工或无法协作；
- “里程碑阻塞”：可先开发，但必须在指定里程碑验收前完成。

## 2. 已完成

- [x] 第一版范围已统一：训练核心、家庭闭环、双场景验证。
- [x] 社区工作端已移出第一版，并保留长期方向说明。
- [x] 后端已统一为 FastAPI 模块化单体。
- [x] AI 最终不直接评分，规则引擎拥有最终评分权。
- [x] 真实电话、完整全双工、声音克隆和自动报警已排除。
- [x] L1 至 L4 降级含义已统一。
- [x] 工程尚未建立和命令尚不可运行已明确标注。
- [x] 文档职责、冲突处理规则和维护范围已建立。

## 3. 启动阻塞项

### 仓库与协作

- [ ] 将当前文档分支评审并合入 `main`，确保团队不再从旧基线开始开发。
- [ ] 确认仓库可见性、成员权限、分支保护和至少一名评审人。
- [ ] 确认 Issue/任务管理方式，并把 M1 拆成可验收的小任务。
- [ ] 确认代码版权归属；若计划公开仓库，选择并添加 `LICENSE`。

### 开发环境

- [x] 确认团队统一使用的 Node.js、pnpm、Python、Docker 和 Docker Compose 版本。
- [x] 在至少一台实际开发设备上验证 MySQL 容器可运行。
- [x] 确认 Windows 11 和 PowerShell 为当前主要开发与容器验收环境，并记录跨平台脚本兼容要求。
- [x] 约定配置分层：`.env.example`、本地 `.env`、测试配置和部署密钥。

验证记录（2026-07-24，Windows 11）：本机 `MySQL57` 占用默认端口 3306，因此通过进程级 `MYSQL_PORT=3307` 覆盖运行 `docker compose up -d mysql`；容器健康状态达到 `healthy`，容器内 `mysqladmin ping` 返回 `mysqld is alive`。验收后运行 `docker compose down`，命名卷 `anxin-training_mysql_data` 已确认保留。

### M1 契约

- [ ] 固定客服退款场景的最小阶段、结束条件和 L4 固定话术。
- [ ] 固定五维评分的首版行为事件、证据格式和确定性规则。
- [ ] 定义最小用户、场景版本、训练会话、轮次、行为事件和评分数据模型。
- [ ] 定义统一 API 错误格式和时间、ID、枚举命名约定。
- [ ] 为 M1 写出可人工执行的主流程验收脚本。

## 4. 里程碑阻塞项

### M2 语音前

- [ ] 比较至少两种 ASR/TTS 方案，并记录价格、延迟、中文效果、数据保留和退出成本。
- [ ] 固定浏览器采集格式、采样率、分片大小和最大音频时长。
- [ ] 定义 WebSocket 消息类型、轮次编号、确认、取消、重连和错误语义。
- [ ] 确定预录语音素材来源、授权和文件管理方式。
- [ ] 确定原始录音默认保留天数，并更新隐私告知和配置示例。

### M3 受控 AI 前

- [ ] 固定 LLM 结构化输出契约、允许策略和禁止内容。
- [ ] 建立越界、提示注入、敏感信息和重复回复测试集。
- [ ] 明确供应商接收的数据字段、区域、保存策略和密钥轮换方式。
- [ ] 用首个语音原型记录延迟和成功率基线，再设定可验证阈值。

### M4 家庭闭环前

- [ ] 为每项家庭权限定义资源、操作、默认值和撤销后的行为。
- [ ] 明确分享确认是单次、限时还是持续授权，并写入需求和数据模型。
- [ ] 完成老人可理解的授权文案和撤销入口评审。

### M7 公网演示前

- [ ] 准备域名、HTTPS/WSS、部署区域、备份和数据删除方案。
- [ ] 准备隐私告知、用户协议、训练免责声明和第三方素材清单。
- [ ] 完成虚构演示账号、可重复演示脚本和 L3 本地包。
- [ ] 验证关闭公网 AI、网络抖动和麦克风拒绝时仍可完成演示。

## 5. 建议的第一次开发启动会输出

启动会只需形成以下可提交结果：

1. M1 Issue 列表和负责人；
2. 版本锁定文件或版本说明；
3. 客服退款 L4 场景配置草案；
4. 首版评分规则表；
5. 最小数据模型和 API 错误约定；
6. M1 人工验收脚本。

供应商选型、社区端和高级语音体验不应阻塞 M1。
