# 系统架构

## 1. 架构结论

第一版采用 Vue 3 PWA + FastAPI 模块化单体 + MySQL 的前后端分离架构。实时训练通过 WebSocket 通信，云端语音识别、语言模型和语音合成通过可替换适配器接入。

采用模块化单体是为了优先验证训练闭环、权限边界和 AI 安全。第一版不拆微服务，不在 API 进程内运行重型本地推理，也不提前引入分布式任务系统。

## 2. 总体结构

```text
老人端 / 家庭端 / 管理端（Vue 3 PWA）
                │
         HTTPS / WebSocket
                │
       FastAPI 模块化单体
                │
 ┌──────────────┼──────────────┐
身份授权     训练引擎       评估复盘
场景内容     家庭协同       安全审计
                │
 MySQL / Redis / MinIO
                │
       AI 服务适配器
 ASR / LLM / TTS / 降级实现
```

前端不直接调用 AI 服务。FastAPI 统一管理身份、训练状态、状态机、安全检查、供应商密钥和降级。

## 3. 后端模块

```text
backend/app/
├── api/              # HTTP 与 WebSocket 入口
├── auth/             # 登录、JWT、角色与资源权限
├── users/            # 用户资料和账号状态
├── family/           # 绑定、分级授权、行动卡和计划
├── scenarios/        # 场景配置、校验、审核和版本
├── training/         # 状态机、轮次和训练会话
├── assessment/       # 行为事件、规则评分和复盘
├── ai/               # ASR、LLM、TTS 适配器
├── safety/           # 脱敏、终止词和真实受骗检测
├── audit/            # 审计和 AI 异常治理
├── storage/          # MySQL、Redis、对象存储
└── common/           # 配置、错误、日志和共享类型
```

模块不得直接访问其他模块的内部表结构或私有实现。跨模块操作通过应用服务和明确的数据类型完成。

## 4. 客户端边界

### 老人端

- 手机优先的 PWA。
- 提供学习、模拟来电、语音测评和复盘。
- 负责采集麦克风、播放音频和呈现状态，不负责评分和安全判断。

### 家庭端

- 适配手机浏览器。
- 负责邀请、授权状态、训练推荐、摘要和行动卡。
- 不具备连接老人实时训练会话的权限。

### 管理端

- 以桌面浏览器为主。
- 管理场景、版本、语音角色、审核、异常和审计。

## 5. 统一训练引擎

### 5.1 场景定义

场景是经过版本化的结构化配置，包含：

- 诈骗者身份和目标；
- 对话阶段及转换条件；
- 允许话术策略和固定话术；
- 风险点、安全行为和结束条件；
- 压力限制、禁止内容和敏感规则；
- 评分映射、复盘材料和家庭行动模板；
- L2、L3 和 L4 降级内容。

### 5.2 状态机

固定学习和动态测评共用同一状态机：

```text
当前阶段
+ 用户本轮表达
+ 已识别行为事件
+ 已使用诈骗策略
+ 安全状态
→ 下一阶段 / 结束 / 安全中止 / 降级
```

固定模式选择审核话术。动态模式只允许 AI 在当前阶段和策略范围内改变表达。

### 5.3 单轮数据流

```text
浏览器上传语音片段
→ ASR 适配器
→ 敏感数据脱敏和真实受骗检测
→ 意图与行为事件识别
→ 状态机决策
→ LLM 生成受控回复
→ 输出安全校验
→ TTS 合成
→ 浏览器播放
→ 持久化脱敏事件与状态
```

安全检查先于正常状态转换。终止词使用本地确定性规则，不依赖大模型。

## 6. 通信与鉴权

### 6.1 HTTPS API

账号、场景、授权、报告和行动卡使用 JSON API。所有写操作执行参数校验、身份验证、资源授权和审计判断。

### 6.2 WebSocket

音频、轮次状态、打断和实时事件使用 `wss://`。

推荐鉴权流程：

```text
HTTPS 登录
→ 后端签发短期 JWT
→ JWT 写入 Secure、HttpOnly Cookie
→ 浏览器建立同源 WSS
→ 后端校验 JWT、Origin、会话所有权和会话状态
→ 通过后 accept
```

长期 JWT 不放入 URL。跨域场景使用通过 HTTPS 签发的短期、单次 WebSocket 票据。

连接期间：

- 关键消息校验训练状态和轮次编号；
- 断线重连重新鉴权；
- 会话结束、账号禁用或权限失效时主动断开；
- 服务端设置最大连接和训练时长；
- 关键状态写入数据库或可恢复的短期存储。

## 7. AI 适配层

业务代码依赖统一接口：

- `SpeechRecognizer`：音频转文本；
- `DialogueModel`：受控回复和行为理解；
- `SpeechSynthesizer`：文本转语音。

每个适配器负责供应商鉴权、请求转换、超时、错误归一化和健康状态。训练引擎只处理统一结果，不包含供应商专用逻辑。

外部请求必须支持取消。当老人主动打断或结束训练时，取消仍在进行的生成和合成任务，避免过期回复被播放。

未来接入本地模型时，将其部署为独立推理进程或服务。FastAPI Web 进程只负责 I/O 编排。

## 8. 数据模型

核心概念：

- `User`、`Role`：用户和角色。
- `FamilyLink`：家庭绑定关系。
- `FamilyPermission`：分项授权和有效状态。
- `Scenario`、`ScenarioVersion`：场景和不可变版本。
- `TrainingSession`：训练会话、版本和运行等级。
- `TrainingTurn`：轮次元数据和处理状态。
- `BehaviorEvent`：脱敏行为、证据、置信度和来源。
- `AssessmentResult`：规则评分和五维结果。
- `ReviewReport`：面向老人的复盘。
- `ShareGrant`：单次分享确认。
- `FamilyActionCard`：家庭行动任务。
- `AudioAsset`：临时音频、过期时间和删除状态。
- `AuditLog`：关键访问和管理操作。

实际字段以 Alembic 迁移和 API 契约为准。

## 9. 数据存储

- MySQL：身份、授权、场景、会话、行为事件、评分和行动卡。
- Redis：短期训练状态、限流、健康状态和可恢复连接信息。
- MinIO/S3：短期录音、预录语音和内容素材。

Redis 不能成为关键业务数据的唯一来源。对象必须带保留策略和过期时间，删除任务需要可审计。

三类存储不要求在工程第一天同时启用。M1 先落地 MySQL；Redis 和对象存储通过抽象接口隔离，在短期状态、语音素材或录音首次进入里程碑时接入。

## 10. 四级降级

| 等级 | 对话 | 语音 | 评分 |
| --- | --- | --- | --- |
| L1 | 动态 AI | 实时 TTS | 规则 + AI 辅助 |
| L2 | 固定分支 | 实时 TTS | 规则 |
| L3 | 固定分支 | 预录语音 | 规则 |
| L4 | 文字按钮 | 无 | 规则 |

降级控制由后端训练引擎执行。降级只改变实现方式，不改变场景版本、评分含义和权限。

## 11. 部署拓扑

### 本机开发

Vue、FastAPI、MySQL、Redis 和 MinIO 运行在开发电脑；外部 AI 通过适配器调用。

### 手机联调

手机通过局域网或临时 HTTPS 访问。由于浏览器麦克风依赖安全上下文，不能把普通 HTTP 局域网访问作为正式语音方案。

### 公网演示

```text
Internet
→ Nginx / HTTPS
→ Vue 静态资源
→ FastAPI
→ MySQL / Redis / MinIO
→ 云端 AI 服务
```

### 本地答辩包

锁定场景版本，使用固定分支、预录语音和规则评分，不依赖公网 AI。

## 12. 架构风险与控制

| 风险 | 控制 |
| --- | --- |
| AI 越过场景边界 | 状态机约束、结构化输出、播放前检查 |
| 语音延迟影响体验 | 流式处理、超时、取消、分级降级 |
| WebSocket 断开丢状态 | 关键事件持久化、短期恢复、轮次编号 |
| 家庭协同变成监控 | 分项授权、老人先查看、默认摘要 |
| 原始录音泄露 | 最少保存、自动过期、访问审计 |
| 单体文件和模块膨胀 | 按领域拆包、应用服务边界、模块测试 |
| 本地模型阻塞 API | 独立推理进程，不在 Web 进程运行 |

## 13. 架构决策

- 后端使用 FastAPI，不使用早期规划的 Spring Boot。
- 第一版使用模块化单体，不拆微服务。
- 动态 AI 是受控测评能力，不是无边界聊天。
- 评分由规则引擎完成，AI 不拥有最终裁决权。
- 第一版不开发社区端、真实电话和声音克隆。
- 第二个场景完成后再评估可视化编排器。
